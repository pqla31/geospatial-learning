# Week 5 Day 2 — CSS 基础：给页面穿衣服

## 今天学什么

前端第二件：**CSS**（层叠样式表）。HTML 是骨架，CSS 是皮肤——颜色、字体、间距、布局全归它管。

Day 1 的页面是纯黑白，今天加一个 `style.css`，刷新后变成现代网页。

## CSS 基本语法

```
选择器 { 属性: 值; 属性: 值; }
```

例：`h1 { color: blue; font-size: 32px; }` —— 所有 `<h1>` 文字蓝色、32px。

## 三种选择器（今天全用到）

| 选择器 | 写法 | 选中谁 | 示例 |
|---|---|---|---|
| 标签选择器 | `h1 { }` | 页面所有该标签 | `body` `h2` `img` |
| 类选择器 | `.card { }` | 带 class 属性的元素 | `<div class="card">` |
| id 选择器 | `#week01 { }` | 带 id 属性的元素（唯一） | `<section id="week01">` |

优先级：id > class > 标签。

## 怎么连起来

HTML 的 `<head>` 里加一行：
```html
<link rel="stylesheet" href="style.css">
```
浏览器加载 HTML 时会顺带加载同目录的 `style.css`。

## 必须理解的 4 个概念

**1. 盒模型** —— 每个元素都是一个盒子，从里到外：
```
content（内容）→ padding（内边距）→ border（边框）→ margin（外边距）
```
`padding` 是盒子内留白，`margin` 是盒子之间的距离。section 卡片化的关键就是 `padding` + `margin`。

**2. 颜色三种写法**：
- 十六进制：`#3498db`（最常用）
- rgba：`rgba(0,0,0,0.08)`（带透明度，投影用的就是它）
- 颜色名：`white` `black`

**3. `:hover` 伪类** —— 鼠标悬停时才生效。导航链接 hover 时出现下划线，就是这个。

**4. `max-width: 100%`** —— 图片自适应。手机屏幕窄，图片缩到和屏幕一样宽不溢出。

## 详细学习步骤（照着做）

### 第 1 步：刷新看效果
用浏览器打开 `01_first_page.html`（或 F5 刷新已打开的）。页面应该变样了。

### 第 2 步：对照源码看结构
VS Code 打开 `style.css`。找到 `header { background: linear-gradient(...) }`——这就是页头那块蓝渐变的来源。

### 第 3 步：改颜色实验（动手）
把 `h2` 的 `border-left` 颜色从 `#3498db` 改成 `#e74c3c`（红色）。保存 → 刷新。
看标题左边的竖线变红了。改回来。

### 第 4 步：改间距实验
把 `section` 的 `margin: 24px 0` 改成 `margin: 60px 0`。刷新。
卡片之间距离拉大了。改回来。

### 第 5 步：用 F12 实时改样式（重点）
1. 浏览器 F12 打开开发者工具
2. 点 Elements 面板左上角的箭头图标（或 Ctrl+Shift+C）
3. 鼠标移到页面某个标题上点击——右侧 Styles 面板显示它的 CSS
4. 在 Styles 面板里直接改一个值（比如把 h2 的 color 改成 red）——页面立刻变，但**不保存到文件**，刷新就没
5. 这个工具是前端调样式的主要方式：先用它试，试好了再写回 style.css

### 第 6 步：加一条自己的规则
在 style.css 末尾加：
```css
/* 学习心得区：绿色左边线 */
#notes {
    border-left: 5px solid #2ecc71;
}
```
刷新，学习心得的标题变成绿色竖线。这就是 id 选择器。

## 一个坑

**改了 CSS 刷新没变化**——八成是浏览器缓存。按 `Ctrl+F5` 强制刷新（跳过缓存）。

## 为什么 CSS 写在单独文件

也可以写在 HTML 的 `<style>` 标签里、甚至元素的 `style=""` 属性里，但**独立 .css 文件**是标准做法：
- 多个页面共用一份样式（Day 4 作品集页直接复用这个 style.css）
- HTML 管结构、CSS 管样式，职责分离
- 改一处全站生效
