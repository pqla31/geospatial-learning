# Week 5 Day 1 — HTML 基础：第一个网页

## 今天学什么

前端三件套的第一件：**HTML**（HyperText Markup Language）。
HTML 不是编程语言，是**标记语言** —— 用标签描述页面的结构。

和 Python 的区别：
- Python 是"指令"（做事情），HTML 是"结构"（描述内容是什么）
- Python 跑起来看输出，HTML 用浏览器打开看页面
- Python 报错会崩，HTML 写错了浏览器照开（只是显示不对）

## HTML 文档结构

```
<!DOCTYPE html>        ← 声明这是 HTML5
<html lang="zh-CN">    ← 根标签，lang 告诉浏览器语言
<head>                 ← 头：浏览器/搜索引擎看的，用户看不到
    <meta charset="UTF-8">   ← 字符编码，中文必须 UTF-8
    <title>页面标题</title>  ← 浏览器标签栏显示的标题
</head>
<body>                 ← 体：用户在页面上看到的所有内容
    ...内容...
</body>
</html>
```

## 常用标签速查

| 标签 | 作用 | 示例 |
|---|---|---|
| `<h1>`~`<h6>` | 标题（6 级） | `<h1>大标题</h1>` |
| `<p>` | 段落 | `<p>一段文字</p>` |
| `<ul>` `<li>` | 无序列表 | `<ul><li>项1</li><li>项2</li></ul>` |
| `<ol>` `<li>` | 有序列表 | `<ol><li>第一</li><li>第二</li></ol>` |
| `<img>` | 图片 | `<img src="路径" alt="描述" width="400">` |
| `<a>` | 链接 | `<a href="网址">文字</a>` |
| `<table>` | 表格 | 见上面速查表本身就是一个 table |
| `<hr>` | 水平线 | 自闭合，不需要 `</hr>` |
| `<!-- 注释 -->` | 注释 | 浏览器不显示，源码里能看到 |

## 语义化标签（HTML5 新增）

| 标签 | 语义 | 放什么 |
|---|---|---|
| `<header>` | 页头 | 标题、导航 |
| `<nav>` | 导航 | 菜单链接 |
| `<main>` | 主体 | 主要内容 |
| `<section>` | 章节 | 一个主题区块 |
| `<article>` | 文章 | 独立内容 |
| `<footer>` | 页脚 | 版权、联系 |

为什么要用语义化标签而不是全用 `<div>`？
- 搜索引擎能理解页面结构（SEO）
- 屏幕阅读器能给视障用户导航
- 代码可读性高（`<header>` 比 `<div class="header">` 直观）

## 怎么跑

前端不用跑脚本，直接双击 `.html` 文件用浏览器打开。
改了代码后刷新浏览器（F5）看变化。

```bash
git add .
git commit -m "feat: week05 day1 练习（HTML 基础 + GIS 学习记录页面）"
git push
```

## 练习方式

和 Python 不一样：前端是"改标签 → 刷新浏览器看变化"的循环。
建议：
1. 先双击打开 `01_first_page.html` 看当前效果
2. 用 VS Code 打开这个文件，改点东西（加个 section、改个标题）
3. 保存 → 刷新浏览器 → 看变化
4. 重复，直到你理解每个标签对应页面上哪一块

## 为什么从 HTML 开始

前端三件套的分工：
- **HTML**：结构（骨架）—— 今天
- **CSS**：样式（皮肤）—— Day 2
- **JavaScript**：交互（肌肉）—— 这学期不学，下学期

先有结构再谈样式。今天的页面很丑（纯黑白），Day 2 加 CSS 后会变好看。
