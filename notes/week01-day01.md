### 03_input_calc.py

```python
# 做一个 NDVI 计算器（现在只用数字，不用真的影像）
# 输入红波段和近红外波段的反射率（0~1 的小数）
# NDVI = (NIR - RED) / (NIR + RED)
# 打印结果，并判断植被覆盖情况：
#   < 0      水体/云
#   0 ~ 0.2  裸土/建筑
#   0.2~0.5  稀疏植被
#   > 0.5    茂密植被
```

这个是为你后面真做遥感影像打底的——公式先在脑子里成型，第五周见到 rasterio 时就是同一件事换了个数据源。

## 常见卡点

- 中文乱码：文件保存成 UTF-8（VS Code 右下角能看到编码）
- `input()` 得到的永远是字符串，算数前要用 `float()` 转
- 除零错误：分母是 0 会直接崩，先用 if 判断
