# Week 1 · Day 3 —— NumPy：把影像当成一个数字块

今天开始不再手写 for 循环处理逐个数据。**一句话概括 NumPy：整个波段是一块数字，整块算。**
真实的一景 Landsat 影像有上亿个像元，用 Python 循环要跑几分钟到几小时，NumPy 是零点几秒——这就是行业里所有人都用它的原因。

时间预算 1.5 小时，目录 `week01-basics/`。环境里已有 numpy 2.0.2。

## 07_numpy_array.py —— 数组基本操作（约 40 分钟）

要求：

1. 从列表建一维数组：`arr = np.array([1, 2, 3, 4, 5])`，打印 `type(arr)`、`arr.shape`、`arr.dtype`
2. 用 `np.arange(12).reshape(3, 4)` 建一个 3 行 4 列的二维数组，打印它的 `shape` 和 `ndim`
3. 索引与切片：
   - 取第 2 行第 3 列：`a[1, 2]`
   - 取第 1 行全部：`a[0, :]`
   - 取前两行、中间两列：`a[0:2, 1:3]`
4. **对比 Python 列表和 NumPy 数组的关键差异**（这一步要亲手试，比看解释清楚）：
   ```python
   print([1, 2, 3] * 2)              # 得到什么？
   print(np.array([1, 2, 3]) * 2)    # 又得到什么？
   ```
5. 聚合统计：`a.mean()`、`a.max()`、`a.min()`、`a.sum()`、`a.std()`
   - 再试 `a.mean(axis=0)`（按列求均值）和 `a.mean(axis=1)`（按行求均值），把结果打出来对比
6. 布尔筛选：`a[a > 5]` 取出所有大于 5 的元素

要点自查：
- `shape` 是 (行数, 列数)，`(6, 4)` 是 6 行 4 列
- `axis=0` 是「跨行」算（结果是每列一个值），`axis=1` 是「跨列」算。这两个最容易搞反，试完把结论记在脑子里

## 08_numpy_ndvi.py —— 一整块影像算 NDVI（约 50 分钟）

用下面这组模拟波段（行=空间位置，列=波段采样点，实际就是一张被缩得很小的影像）：

```python
nir = np.array([
    [0.45, 0.42, 0.40, 0.38],
    [0.30, 0.28, 0.32, 0.29],
    [0.05, 0.06, 0.04, 0.07],
    [0.50, 0.48, 0.46, 0.44],
    [0.35, 0.33, 0.31, 0.30],
    [0.10, 0.12, 0.09, 0.11],
])
red = np.array([
    [0.08, 0.09, 0.10, 0.11],
    [0.28, 0.27, 0.30, 0.28],
    [0.12, 0.13, 0.10, 0.14],
    [0.06, 0.07, 0.08, 0.09],
    [0.20, 0.19, 0.18, 0.17],
    [0.11, 0.13, 0.10, 0.12],
])
```

要求：

1. **一行算完整个 NDVI**，不许写循环：
   ```python
   ndvi = (nir - red) / (nir + red)
   ```
2. 打印 `ndvi.shape` 确认是 (6, 4)，再用 `np.round(ndvi, 2)` 打印成易读的矩阵
3. 统计并格式化输出：整景均值、最大值、最小值、像元总数（`ndvi.size`）
4. 用布尔掩膜算**植被覆盖率**（NDVI > 0.4 的像元占比）：
   ```python
   coverage = (ndvi > 0.4).mean() * 100
   print(f'植被覆盖率：{coverage:.1f}%')
   ```
   这一步是全文件的精髓：`ndvi > 0.4` 得到一块 True/False，`.mean()` 就是 True 的占比
5. 额外挑战：用 `np.where` 把 NDVI 分成 3 档（-1 水体、0 裸土、1 植被），输出一块整型矩阵

**自检输出**（你跑出来应该跟这一模一样）：

```
NDVI 矩阵:
[[ 0.7   0.65  0.6   0.55]
 [ 0.03  0.02  0.03  0.02]
 [-0.41 -0.37 -0.43 -0.33]
 [ 0.79  0.75  0.7   0.66]
 [ 0.27  0.27  0.27  0.28]
 [-0.05 -0.04 -0.05 -0.04]]
均值 0.202 | 最大 0.786 | 最小 -0.429
植被覆盖率(>0.4): 33.3%
像元总数: 24
```

要点自查：
- 第一行全是 0.5 以上（茂密植被）、第三行全负（水体）——数据是我按这个规律造的，跑出来对不上说明公式写反了
- 第三行为负是**正确的**，别以为算错了
